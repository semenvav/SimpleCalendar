| Этап | Содержание |
|---|---|
| **M0** | Gradle-проект (Kotlin), Dockerfile multi-stage (Vite-сборка → JRE), compose с Baikal для разработки, labels для Traefik, healthcheck |
| **M1** | discovery коллекций, синхронизация через `sync-collection` с откатом на `ctag`, кэш сырых `.ics` в SQLite, разворачивание повторений на лету, `GET /api/events?from&to`, фронт на Event Calendar: месяц / два месяца рядом / неделя / список, цвета календарей → **висит на стене, показываем семье** |
| **M2** | создание, правка, удаление простых событий, `If-Match` по ETag и обработка 412, тач-форма события, оптимистичные обновления |
| **M3** | своя склейка мастера с переопределениями поверх `Recur`, корпус `.ics`-фикстур, round-trip тесты против Baikal в контейнере, UI выбора «только это / это и последующие / все» |
| **M4** | админка (календари, цвета, люди), две раскладки, тема — и правки по конкретным отзывам семьи; здесь же решаем, нужны ли свои компоненты вместо библиотеки |
| **M5** | погода, Home Assistant, Immich, подписки на внешние ICS (праздники, школьное расписание) |

M4 по факту не столько этап, сколько непрерывный процесс начиная с конца M1 — ради этого и берём готовую библиотеку.
